# Integration gates

- Actual common application must compile.
- GLOBAL selection must consult only the common root feed.
- PET updates must preserve the three common binaries, database and license.
- Invalid packages, other identities and downgrades must be refused.
- Interrupted PET updates must restore the verified previous PET through the external SYSTEM recovery task.
- Publication requires complete migration and operational regression evidence; fixture success alone is insufficient.
